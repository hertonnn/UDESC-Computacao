## 1. Exercícios de Inequações

### Questão 1 (FUVEST)
O conjunto solução de $(-x^2 + 7x - 15) \cdot (x^2 + 1) < 0$ é:
*   **a)** $\{\}$
*   **b)** $[3, 5]$
*   **c)** $\mathbb{R}$
*   **d)** $[-1, 1]$
*   **e)** $\mathbb{R}_+$

### Questão 2 (FUVEST)
O conjunto das soluções, no conjunto $\mathbb{R}$ dos números reais, da inequação:
$$ \frac{x}{x+1} > x $$
é:
*   **a)** vazio
*   **b)** $\mathbb{R}$
*   **c)** $\{x \in \mathbb{R} \mid x < 0\}$
*   **d)** $\{x \in \mathbb{R} \mid x > -1\}$
*   **e)** $\{x \in \mathbb{R} \mid x < -1\}$

### Questão 3 (ANGLO)
Os valores de $x$ que satisfazem a inequação:
$$ \frac{x-1}{x} > 1 $$
são tais que:
*   **a)** $x > 0$
*   **b)** $x < 0$
*   **c)** $x > 1$
*   **d)** $x < 1$
*   **e)** $0 < x < 1$

### Questão 4 (PUC-SP)
No universo $\mathbb{R}$, o conjunto solução da inequação:
$$ \frac{x-3}{3x-x^2} < 0 $$
é:
*   **a)** $\{x \in \mathbb{R} \mid x > 0\}$
*   **b)** $\{x \in \mathbb{R} \mid x > 3\}$
*   **c)** $\{x \in \mathbb{R} \mid x < 0 \text{ ou } x > 3\}$
*   **d)** $\{x \in \mathbb{R} \mid 0 < x < 3\}$
*   **e)** $\{x \in \mathbb{R} \mid x > 0 \text{ e } x \neq 3\}$

### Questão 5 (PUC-04)
Quantos números inteiros e estritamente positivos satisfazem a sentença:
$$ \frac{1}{x-20} \leq \frac{1}{12-x} $$
*   **a)** $16$
*   **b)** $15$
*   **c)** $14$
*   **d)** $13$
*   **e)** MENOS QUE $13$

## 2. Gabarito Consolidado

*   **Questão 1:** **c)** $\mathbb{R}$
*   **Questão 2:** **e)** $\{x \in \mathbb{R} \mid x < -1\}$

*   **Questão 4:** **e)** $\{x \in \mathbb{R} \mid x > 0 \text{ e } x \neq 3\}$
