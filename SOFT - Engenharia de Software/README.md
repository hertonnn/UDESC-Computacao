## 📌 Requisitos Funcionais vs Não-Funcionais  

🔹 **Funcionais** → *“o que” o sistema deve fazer*  
   - Funcionalidades ou serviços a serem implementados.  
   - Exemplo em **Home-Banking**:  
     - 📌 Informar saldo da conta  
     - 📌 Realizar transferências  

🔹 **Não-Funcionais** → *“como” o sistema deve operar*  
   - Restrições, desempenho e qualidade do serviço.

## 🎮 Simulação com o SimSE

O **SimSE** é um jogo educacional que simula processos de desenvolvimento de software em uma *software house*.  

📌 Modelos disponíveis:  
➡️ Cascata | ➡️ Incremental | ➡️ RAD | ➡️ Prototipação | ➡️ RUP | ➡️ XP  

🕹 **Tarefa:**  
- Jogar o **modelo Cascata**  
- Atingir no mínimo **Score 65**  
- Fazer **print** da tela *Artifacts-At-A-Glance*  
- Fazer o **upload do resultado**  

🔗 **Download do Jogo:** [Waterfall.jar](https://www.ics.uci.edu/~emilyo/SimSE/downloads/newJars/waterfall.jar)  

📺 **Videoaula Gerenciamento de Configuração de Software:** [YouTube](https://www.youtube.com/watch?v=_8Bny3Q4o_g)
