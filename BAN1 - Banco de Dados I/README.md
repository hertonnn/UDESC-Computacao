# 💾 Banco de Dados 1

![Banco de Dados](https://github.com/hertonnn/UDESC-Computacao/blob/master/utils/img/img_ban1.png?raw=true)

Os **bancos de dados** são conjuntos organizados de dados, geralmente contendo registros sobre pessoas, lugares ou informações em geral. São fundamentais para **sistemas de informação** e **segurança**, muitas vezes mantendo sua estrutura inalterada por longos períodos.

A gestão desses dados é feita por **Sistemas Gerenciadores de Bancos de Dados (SGBD)**, tecnologia que surgiu na década de 1970. A partir dos anos 1980, os **SGBDs relacionais** dominaram o mercado — e continuam amplamente utilizados atualmente.

---

## 📘 Tópicos da Disciplina

### 📖 Introdução

Aborda os conceitos fundamentais de banco de dados, como definição, tipos de dados, vantagens sobre sistemas de arquivos e a importância dos SGBDs.  
🔗 Referência: *Database System Concepts* – Silberschatz, Korth & Sudarshan

---

### 🧠 Modelagem Conceitual

Envolve a criação de um **modelo de alto nível** que descreve os dados e seus relacionamentos, geralmente usando o modelo **Entidade-Relacionamento (ER)**.  
✔️ Objetivo: facilitar a comunicação entre usuários e projetistas.  
🔗 Referência: *Fundamentos de Sistemas de Banco de Dados* – Elmasri & Navathe

---

### 🧩 Modelagem Lógica

Tradução do modelo conceitual para um modelo lógico (como o **modelo relacional**), respeitando as restrições de integridade e projetando chaves primárias e estrangeiras.  
🛠️ Ferramentas comuns: SQL, MySQL Workbench, PostgreSQL.  
🔗 Referência: *Modelagem Conceitual e Projeto de Banco de Dados* – Heuser

---

### 🧼 Normalização

Processo de organização dos dados para **eliminar redundâncias** e garantir integridade. Utiliza **formas normais** (1FN, 2FN, 3FN, BCNF).  
📌 Ajuda a evitar anomalias de inserção, exclusão e atualização.  
🔗 Referência: *Database Systems: A Practical Approach to Design, Implementation, and Management* – Connolly & Begg

---

### 🔢 Álgebra Relacional

É a linguagem formal para manipulação de dados em modelos relacionais. Utiliza operações como:  
- Seleção (σ)  
- Projeção (π)  
- Junção (⨝)  
- União (∪)  
- Diferença (−)  
- Produto cartesiano (×)  
🔗 Ferramenta: [RelaX Calculator](https://dbis-uibk.github.io/relax/landing)

---

### 🛢️ SQL (Structured Query Language)

Linguagem padrão para acesso e manipulação de dados em bancos relacionais. Divide-se em:  
- **DDL** (Data Definition Language): `CREATE`, `ALTER`, `DROP`  
- **DML** (Data Manipulation Language): `SELECT`, `INSERT`, `UPDATE`, `DELETE`  
- **DCL** (Data Control Language): `GRANT`, `REVOKE`  
🔗 Referência: [W3Schools SQL Tutorial](https://www.w3schools.com/sql/)

---

### 🌐 BDs NoSQL

Bancos de dados não relacionais, ideais para grandes volumes de dados, alta escalabilidade e desempenho. Tipos comuns:  
- **Documentos**: MongoDB  
- **Colunar**: Cassandra  
- **Chave-valor**: Redis  
- **Grafos**: Neo4j  
🔗 Referência: *NoSQL Distilled: A Brief Guide to the Emerging World of Polyglot Persistence* – Pramod J. Sadalage & Martin Fowler
