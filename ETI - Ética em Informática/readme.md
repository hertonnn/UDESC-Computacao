## 1. Fundamentos Teóricos: Ética, Moral e História

### 🧠 A. Definições Chave

* **Moral:** A prática (*"o que fazemos"*). Conjunto de regras, costumes e normas de uma sociedade específica em um tempo específico.
* **Ética:** A teoria (*"por que fazemos"*). É a ciência que estuda o comportamento moral e busca princípios universais.
* **Valor:** O "peso" ou importância dada a algo (ex: honestidade, liberdade).
* **Virtude:** Disposição constante de praticar o bem.

### 🆚 B. Diferença Prática

| Conceito | Característica Principal | Exemplo |
| :--- | :--- | :--- |
| **Moral** | Prática, Cultural, Temporal | "Não andar pelado na rua" (regra social) |
| **Ética** | Teórica, Universal, Reflexiva | "Por que não devemos causar dano ao outro?" |
| **Valor** | Importância atribuída | Dar valor à "Privacidade" acima do "Lucro" |

### 🏛️ C. História e Correntes Filosóficas

#### Immanuel Kant (Deontologia)
> **O Dever Racional:** O ser humano é racional e deve agir por dever. Uma ação é ética se seguir uma regra universal, independentemente das consequências.

#### Utilitarismo (Consequencialismo)
> **O Maior Bem:** Foca no resultado. A ação certa é a que produz o maior bem para o maior número de pessoas (Beneficência).

#### Teoria da Ética: Positivismo vs. Jusnaturalismo

* **Positivismo (A Lei é a Lei):** Só existem as leis criadas pelo Estado. Se está escrito e aprovado, é válido, independente de ser "justo".
* **Jusnaturalismo (Direito Natural):** Existem princípios universais (vida, liberdade) que nascem com o humano. Se uma lei escrita viola isso, ela não é moralmente válida.

## 2. O Raciocínio Ético (Decisões)

**Definição:** Habilidade cognitiva (não inata, deve ser aprendida) de avaliar consequências e escolher o melhor caminho.

### ⚠️ Os 3 Pilares da Decisão (Cai em Prova)

1.  **Dever Moral:** Obrigação de agir conforme valores.
2.  **Avaliação das Consequências:** Analisar impactos positivos/negativos.
3.  **Aplicação dos Princípios:** Usar regras éticas (Justiça, Honestidade).

### Tipos de Raciocínio
* **Dedutivo:** Geral ➡️ Específico.
* **Indutivo:** Específico ➡️ Geral.
* **Analítico:** Dividir o problema em partes menores.

## 3. Ética Profissional e Códigos (SBC e Confea)

### 🛡️ Princípios Fundamentais
* **Autonomia:** Capacidade de decisão livre.
* **Beneficência:** Fazer o bem coletivo.
* **Não Maleficência:** Não causar danos.
* **Justiça:** Equidade e imparcialidade.
* **Confidencialidade:** Sigilo e proteção de dados.

### 💻 Código de Ética da SBC (Resolução 2024)
O profissional de computação deve:
1.  **Evitar Danos:** Físicos, mentais, ambientais ou aos dados.
2.  **Honestidade:** Ser transparente sobre limitações do sistema; não aceitar subornos.
3.  **Justiça e Não Discriminação:** O código proíbe discriminação. Sistemas devem ser inclusivos.
4.  **Propriedade Intelectual:** Respeitar autoria e licenças.
5.  **Privacidade:** Coletar o mínimo de dados necessários.

## 4. Temas Sociais: Direitos Humanos e Raça

> 📢 **Atenção:** A tecnologia não é neutra; ela pode reforçar desigualdades se não for desenvolvida com ética.

### Raça vs. Etnia

* **Raça (Conceito Social/Político):** Cientificamente, não existem raças humanas biológicas. Sociologicamente, refere-se a como grupos são tratados com base em características físicas (fenótipo). É o foco do racismo.
* **Etnia (Identidade Cultural):** Grupo que compartilha língua, religião, cultura e história (ex: Banto, Iorubá).

### Viés Algorítmico e Justiça
É uma violação ética criar sistemas que discriminam (ex: reconhecimento facial falho para peles negras). O princípio da **Justiça** exige tratar os desiguais de forma desigual para gerar equidade (reparação histórica).

## 5. Exercícios de Fixação

### 📝Parte 1: Conceitos Teóricos (Clique para ver as questões)

**Q1.** Qual a principal diferença entre Moral e Ética?

a) Moral é universal; Ética é temporária.

b) Moral é prática (costumes); Ética é reflexão teórica.

c) São sinônimos.

**Q2 (Kant).** O que permite ao homem cumprir regras e obrigações?

a) Medo da punição.

b) Sua condição racional.

c) Busca pelo lucro.

**Q3 (SBC).** Um algoritmo falha 10x mais com pessoas negras. Qual princípio é violado?

a) Honestidade.

b) Justiça e não discriminação.

c) Autonomia.

**Q4.** Relacione:

( A ) Beneficência | ( B ) Não Maleficência | ( C ) Justiça

( ) Evitar causar danos.

( ) Buscar o bem-estar coletivo.

( ) Tratar com equidade e imparcialidade.

> **Gabarito Parte 1:**
> 1. **B** (Moral = Prática; Ética = Teoria)
> 2. **B** (Condição Racional)
> 3. **B** (Viola a justiça e inclusão)
> 4. **B, A, C**


### Parte 2: Prática e Estudos de Caso

**Q1.** Quais os três elementos essenciais na ética de decisão?

a) Lucro, velocidade, leis.

b) Dever moral, avaliação das consequências, aplicação dos princípios.

c) Intuição, ordens, custos.

**Q2.** Relacione os princípios:

( A ) Não Maleficência | ( B ) Confidencialidade | ( C ) Justiça | ( D ) Beneficência

( ) Segredo/Privacidade.

( ) Não causar danos.

( ) Agir no interesse/bem-estar coletivo.

( ) Equidade/Distribuição justa.

**Q3.** Verdadeiro ou Falso:

( ) O raciocínio ético é inato (nascemos sabendo).

( ) Ética profissional é só para profissões regulamentadas.

( ) O raciocínio ético pode ser aprendido.

**Q4 (Caso).** Gerente ordena ignorar falha de segurança para entregar no prazo. O dev obedece. Quais violações ocorreram (SBC)?

a) Apenas autoria.

b) Evitar danos, Honestidade e Privacidade.

c) Nenhuma (obedeceu ordens).

> **Gabarito Parte 2:**
> 1. **B**
> 2. **B, A, D, C**
> 3. **F, F, V** (Não é inato, permeia tudo, pode ser aprendido)
> 4. **B** (Violação grave de honestidade e segurança)
