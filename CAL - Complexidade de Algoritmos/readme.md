# 📘 Complexidade de Algoritmos

![img_cal](https://assets.dio.me/mXTGm3bNZi56BV-Cvjqoy50RjjYvsMerjEKWKpRS4J8/f:webp/q:80/L2FydGljbGVzL2NvdmVyL2M2YmFlYzAzLTVmZGItNGVlYS1iOWVhLTYyZDI3YTI4ZDkyYS5wbmc)

A complexidade de um algoritmo mede quão eficientemente ele usa recursos, como tempo (velocidade) e espaço (memória), em relação ao tamanho da entrada do problema. Para analisá-la, usamos a notação Big O (O-grande) (ou O(n)), que descreve a taxa de crescimento do uso de recursos no pior cenário, ignorando constantes e termos menores para focar na tendência geral de escalabilidade. Algoritmos com complexidade menor são mais eficientes para grandes volumes de dado
