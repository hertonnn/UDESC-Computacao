## 🚀 O que é ODAW?

**Desenvolvimento de Aplicações na Web (ODAW)** abrange o histórico e os conceitos fundamentais relacionados à Internet e à Web. O objetivo da disciplina é capacitar o aluno no conhecimento das tecnologias e desenvolvimento de um ambiente/aplicação protótipo completo.

A ementa explora desde o design estático até o dinâmico (com acesso a banco de dados), unindo o desenvolvimento orientado ao usuário com conceitos vitais de **Acessibilidade**, **Usabilidade**, **Design Responsivo** e **Segurança na Web**.

## 📋 Controle de Atividades (Moodle)

Abaixo está o log de todas as atividades exigidas na plataforma da disciplina ao longo do semestre, aplicadas iterativamente no projeto principal e nos diretórios de estudo:

### 📄 Módulo 1: Estruturação e Marcação (HTML)
- [x] **Exercício 1 (HTML Introdução):** Escolha do tema e criação da página inicial (textos variados, imagens, links).
- [x] **Exercício 2 (Listas e Tabelas):** Adição de listas (tipos variados), tabelas explorando tags de aula e um formulário contendo campos diversos.
- [x] **Exercício 3 (HTML 5):** Implementação de tags semânticas, novos tipos/atributos de formulário, mídia (áudio/vídeo) e elementos gráficos (Canvas, SVG).

### 🎨 Módulo 2: Design e Layout (CSS)
- [x] **Exercício 4 (CSS Inicial):** Configuração base seguindo tutorial em PDF e experimentação de alterações extras de estilos.
- [x] **Exercício 5 (Estilos e Classes):** Redefinição de tags HTML, criação de classes/IDs e aplicação das 3 formas de CSS: Externo, Interno (tag style) e Inline.
- [x] **Exercício 6 (Templates e Frameworks):** Criação de um layout mais elaborado utilizando RWD Frameworks (Bootstrap, W3.CSS, Pure CSS) ou templates.

### ⚡ Módulo 3: Interatividade e Dinamismo (JavaScript)
- [x] **Exercício 7 (JS Inicial):** - Formulário com alteração para maiúsculas/minúsculas.
  - Verificação de campos obrigatórios com alerta de erro/sucesso.
  - Script via `prompt` que retorna saudação dinâmica baseada na hora e data atual.
- [x] **Exercício 8 (JS no Projeto):** Integração de no mínimo 5 funcionalidades no projeto principal (validações de regex/datas, manipulação do DOM, funções matemáticas e controle de strings/vetores).

### ⚙️ Módulo 4: Backend e Regras de Negócio (PHP)
- [x] **Exercício 9 (PHP Inicial):** - Exibição de data/hora atual.
  - Uso de `function` e manipulação de Strings/Arrays.
  - Contador de visitas baseado em arquivo `.txt`.
  - Implementação de "Cookies" e/ou "Sessions".
- [x] **Exercício 10 (PHP Integrado):** Validação server-side de formulários (GET/POST), exibição de mensagens de erro interativas, validação de login via `autenticacao.txt` e pesquisa sobre cifragem de senhas.

### 🗄️ Módulo 5: Banco de Dados (MySQL)
- [x] **Exercício 11 (MySQL Inicial):** Execução de scripts via terminal/interface para criação de base de dados, tabelas e testes de CRUD (Insert, Update, Select, Delete).
- [x] **Exercício 12 (PHP + MySQL):** Conexão do backend em PHP com o banco de dados. Implementação final de um formulário de cadastro dinâmico com operações completas de inserção, visualização, alteração e exclusão de registros de veículos.
