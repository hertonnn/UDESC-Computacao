# Software Foundations — Logical Foundations  
[*Prefácio & visão geral*](https://softwarefoundations.cis.upenn.edu/lf-current/toc.html)

## 🔍 Introdução

O “Logical Foundations” é o Volume 1 da série *Software Foundations*, cujo propósito é estabelecer os alicerces formais para construção de software confiável. 
Ele introduz, de forma rigorosa e interativa com Coq (agora “Rocq”), os conceitos de:

- Programação funcional  
- Lógica construtiva  
- Prova assistida por computador  

O diferencial do livro é: **100 % formalizado e verificável por máquina** — o texto é um *script* Coq completo.

## 🧷 Temas principais

| Tema | Descrição |
|------|-----------|
| **Lógica** | Fundamentos da lógica formal e sua aplicação em especificações de programas |
| **Provas & Assistentes** | Uso de Coq/Rocq para construir argumentos formais e extrair programas de provas |
| **Programação funcional** | Funções puras como ponte entre lógica e software, simplificando raciocínios |

Esses três fios conceituais (lógica, provas, funcional) são entrelaçados no desenvolvimento do livro.

## 📚 Estrutura e uso

- O livro é pensado para uma leitura acoplada ao Coq: cada capítulo é acompanhado por scripts formais e exercícios que devem ser feitos em Coq. 
- Os capítulos “core” formam um percurso linear típico de um semestre (introdução, listas, lógica, táticas, etc.).  
- Há capítulos “offshoot” opcionais para aprofundamento.  
- Não é exigido background prévio em lógica ou PL, mas maturidade matemática ajuda.

## 🎯 Por que estudar este material?

1. **Rigor formal** — você aprende programação e raciocínio lógico com precisão matemática.  
2. **Transferência prática** — os conceitos aqui servem de base para técnicas de verificação mais avançadas.  
3. **Ferramentas reais** — uso direto de Coq / Rocq para experimentar e internalizar as ideias.

## 📖 Como começar

1. Instale Coq / Rocq (existem guias no prefácio do livro). 
2. Inicie a leitura do Prefácio e os primeiros capítulos com scripts correspondentes.  
3. Tente resolver os exercícios no ambiente Coq — isso é parte central do aprendizado.  
4. Use os capítulos extras conforme interesse ou necessidade de aprofundamento.
